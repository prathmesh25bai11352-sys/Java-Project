**Problem Statement:** Developing reliable decision-making agents for adversarial zero-sum environments requires exploring all possible future states rather than relying on basic heuristics. 

**Scope of the Project:** A Java-based console application simulating a Tic-Tac-Toe environment that utilizes the recursive Minimax algorithm to evaluate game trees, ensuring the artificial intelligence never loses. 

**Target Users:** AI students, computer science educators, and game logic developers. 

**High-Level Features:** 
* Interactive console-based game board.
* Recursive Minimax search algorithm for optimal move calculation.
* Dynamic state evaluation to assign numerical scores to win/loss/draw states.
* Input validation for robust user interaction.
